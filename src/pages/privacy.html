Deadlock2Dire Privacy Policy

Effective date: May 29, 2026

Summary

Deadlock2Dire does not collect, sell, share, or transmit personal information.

What the extension reads

Deadlock2Dire runs only on Deadlock forum pages matched by the extension. It reads visible patch-note content on the current page so it can render that content in a different layout.

Local storage

Deadlock2Dire does not store personal data. The extension uses bundled icon assets and does not require user accounts, profiles, or browsing history.

Network requests

Deadlock2Dire does not intentionally send personal data, browsing history, account information, or user-generated content to external services.

Remote code

Deadlock2Dire does not load or execute remote JavaScript or WebAssembly. Extension JavaScript is included in the extension package.

Analytics and advertising

Deadlock2Dire does not use analytics, advertising, tracking pixels, or behavioral profiling.

Data sharing

Deadlock2Dire does not sell, rent, or share user data.

Data removal

You can remove Deadlock2Dire data by uninstalling the extension or clearing extension storage in your browser settings.

Limited Use

The use of information received from browser APIs complies with applicable browser extension user data policies, including Limited Use requirements.

Contact

For privacy questions, open an issue at github.com/aisatan/Deadlock2Dire/issues.
